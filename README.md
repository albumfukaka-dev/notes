# notes

一个研究型仓库。用来和 Claude 一起长期研究课题、记录发现、凝结颗粒。

不是资料堆，也不只是想法记录：重点是**研究和发现**——从底层逻辑出发，往上搭结构，最后落成能直接用的结论。

## 当前课题

**[反差](研究/反差/)** · v0.2 · 当下判断：这个时代的平均值是 AI 腔，反差的能量在"人"这一边；人设反差 = 真实特质 × 对着时代平均值 × 能持续产出。→ [看结论](研究/反差/README.md)

## 目录

```
notes/
├── README.md            你正在看的
├── CLAUDE.md            给 Claude 的协作约定（每次新会话会自动读）
├── 灵感.md               共同记录的灵感：谁冒出来的就标谁
├── 研究/                 一个课题一个文件夹
│   └── 反差/             当前主课题
│       ├── README.md     ★ 结论先行：当下判断、可做的动作、方法、研究地图
│       ├── 01 ~ 07       研究过程：原理 → 分类 → 谱系 → 时代 → 媒介 → 风险 → 当下趋势
│       ├── 案例/          案例库 + 图片
│       └── 图解/          原理示意图
└── 颗粒/                 从对话里凝结出的关键词、金句、思维链
```

## 怎么用

- 开新会话时，选上 `notes` 仓库，说一句"继续研究反差"就能接上。
- 每个课题打开文件夹，第一眼就是**结论**（README）；研究过程在编号文件里。
- 灵感随时记进 `灵感.md`。
- 聊过几轮后凝结颗粒，打磨定稿后放进 `颗粒/`。
